# Insight Addons 1.16.0 (NeoForge 1.21.1)

InSight Chests(`insightchests` 1.21.1 NeoForge 1.0.4) 애드온입니다.

## 기능

1. **바라보는 보관함 옆 3D 표시** — 시선이 닿은 보관함 하나만 표시하고, 시선을 떼면 사라집니다. 바닐라 상자/통/셜커/엔더 상자, Sophisticated Storage, Sophisticated Backpacks(놓인 것), Create 금고/슈트/툴박스 옆에 내용물을 3D로 띄웁니다.
   가장 많은 아이템이 앞에 크게, 나머지는 뒤쪽 줄에 작게 나오고 모두 개수가 붙습니다. 보관함 종류에 맞는 색의 테두리와 이름, 총 개수·종류가 표시됩니다. 배낭은 업그레이드 아이콘도 표시됩니다.
2. **서버에 모드가 없어도 동작하는 "기억" 방식** — 보관함을 열면 서버가 보내주는 메뉴 슬롯을 읽어 위치별로 기억하고, 그 뒤 옆에 3D로 표시합니다. 열었던 시점의 내용이며 "N분 전 기록"으로 표시됩니다.
3. **서버에도 이 모드가 있으면 실시간** — 열지 않아도 내용물이 정확하게 보이고, Create 금고도 지원됩니다. 싱글플레이는 항상 실시간입니다.
4. **Create 렌치 스캔** — 렌치를 들면 주변 보관함의 Create 아이템을 플레이어 주변에 궤도로 띄웁니다. 시선이 가는 아이템이 든 보관함은 금색 테두리와 연결선으로 표시되고, 해당 아이템이 든 모든 보관함 위에 "이름 x개수" 라벨이 벽 너머에서도 항상 보입니다.
5. **InSight Chests 연동** — Sophisticated 배낭/저장소, 바닐라 통, 셜커 상자를 열 때 InSight Chests의 카메라 전환과 3D 아이템 연출을 적용합니다. 바닐라 통/셜커는 InSight Chests의 유리 화면으로 열립니다.
   **유리 스킨 (1.5.0)** — Sophisticated 화면은 기능(업그레이드 탭, 설정 패널, 정렬 등)은 원래 그대로 두고, 배경 패널, 슬롯 칸, 업그레이드 띠, 컨트롤/탭 배경만 서리 유리로 바꿉니다. 설정 `glassSkin`, `glassOpacity`로 끄거나 불투명도를 조절합니다.
6. **JEI 조합 재료 표시 (1.4.0)** — JEI 레시피 화면의 "+" 버튼 아래에 작은 상자 모양 버튼이 생깁니다. 누르면 화면이 닫히고, 그 레시피의 재료가 플레이어 앞에 3D로 뜹니다.
   재료마다 "가진 개수/필요한 개수"(부족하면 빨간색)가 붙고, 그 재료가 든 보관함에 같은 색 테두리와 연결선, "이름 xN" 라벨이 벽 너머에서도 보입니다. 이때 다른 표시(바라보는 보관함, 렌치)는 모두 숨겨집니다. 버튼을 다시 누르거나 90초가 지나면 꺼집니다.
   태그로 대체 가능한 재료(예: 아무 판자)는 주변에 가장 많은 것을 보여줍니다. 서버에 이 모드가 있으면 반경 안 모든 보관함을 실시간으로 찾고, 없으면 열어 본 보관함의 기억에서 찾습니다.

## 1.8.0 변경점

- **"이 아이템 찾기" 버튼 추가** (JEI와 EMI 모두): 기존 "재료 찾기" 버튼 옆/아래에 돋보기 모양 버튼이 하나 더 생깁니다. 이 버튼은 레시피의 재료가 아니라 **마우스를 올려 두었던 그 아이템 자체**를 주변 보관함에서 찾아 3D로 띄우고 들어 있는 보관함을 표시합니다. 아이템에 마우스를 올렸다가 버튼을 누르세요. 올려 둔 아이템이 없으면 레시피의 결과 아이템을 찾습니다. 버튼에 마우스를 올리면 지금 찾을 아이템 이름이 툴팁에 나옵니다.

## 1.7.0 변경점

- **재료 찾기 정리**: 인벤토리에 이미 충분히 있는 재료는 3D로 띄우지 않고 "인벤토리에 있음: ..." 글씨로만 알려 줍니다. 인벤토리에도 보관함에도 없는 재료는 3D로 띄우지 않고 "보관함에 없음: ..."으로 표시합니다. 보관함에서 꺼내면(열어서 가져가면) 그 보관함 표시는 자동으로 사라집니다. 마우스 휠 선택은 3D로 보이는 재료 사이에서만 돌아갑니다.
- **다른 사람의 조합 연출 (서버에도 이 모드 필요)**: 작업대, 대장장이 작업대, 모루, 석재절단기, 베틀, 지도 제작대, 숫돌에서 누가 결과를 꺼내면 근처(48블록)의 이 모드가 있는 플레이어에게 재료가 날아가는 연출이 보입니다. 재료가 그 사람 인벤토리에 있으면 그 사람에게서, 없고 작업대 근처 8블록 안 보관함에 있으면 그 보관함에서 날아옵니다. Jade나 WTHIT는 바라보는 블록의 정보만 받아서 다른 사람의 조합을 알 수 없으므로, 이 모드를 서버에도 넣어야 합니다. (서버에 이 모드가 없으면 내가 조합할 때의 연출만 보입니다.)
- **Fancy Items 빛 효과**: 보관함 안에서 떨어지는 3D 아이템 뒤에 아이템 등급 색의 후광을 그립니다(일반 등급 제외, 마법 부여 빛이 있으면 보라색). 설정 `itemGlow`(auto/on/off), `fancyModIds`로 기준 모드 ID를 지정합니다.

## 1.6.0 변경점

- **배낭/Sophisticated 화면**: InSight Chests의 `guiPosition`(기본 오른쪽)대로 화면을 옮기고, 투명도도 InSight Chests의 `uiBackgroundOpacity`와 같은 값을 씁니다. 월드를 어둡게/흐리게 하는 배경을 그리지 않아서 3D 아이템이 보입니다. 글씨는 밝은 색으로 바뀝니다.
- **리소스팩**: `assets/insight_addons/textures/gui/glass_panel.png`, `glass_control.png`(16x16, 모서리 4px), `glass_slot.png`(18x18)를 리소스팩에 넣으면 유리 대신 그 이미지로 그립니다. 배낭/통 내부 질감은 바닐라 블록 질감 경로를 쓰므로 리소스팩이 그대로 반영됩니다.
- **떨어지는 3D 아이템 개수**: 기본은 실제 개수 그대로(1:1)입니다. 보관함 화면 아래 슬라이더로 1:1 / 절반 / 원래 방식을 고르고, 설정 `dropRatio`, `dropMaxTotal`(전체 상한)로도 조절합니다.
- **배낭 내부 질감**: 양털 대신 갈색 테라코타. 설정 `backpackCavityTexture`로 바꿉니다.
- **바라보기 표시**: 작은 아이콘을 격자로 최대 56종까지 띄우고, 개수 글씨가 아이템에 가려지던 문제를 고쳤습니다.
- **EMI**: EMI가 있으면 EMI 레시피 화면의 "+" 옆에 같은 찾기 버튼이 붙습니다. (EMI 내부 구조에 의존)
- **재료 찾기 선택**: 마우스 휠로 재료를 넘기면 그 재료가 든 보관함이 강조됩니다. (이 동안 핫바 스크롤이 막힘, 설정 `scrollToSelect`)
- **Fancy Items**: 설치되어 있으면 떨어지는 아이템 크기를 아이템 실제 크기에 맞춥니다. (`itemSizeScaling`)
- **조합 연출**: 작업대 등에서 결과를 누르면 재료가 플레이어나 기억된 보관함에서 작업대로 날아갑니다. 내가 조합할 때만 보입니다.

## 데이터가 오는 방식 (중요)

| 대상 | 서버에 모드 없음 | 서버에 모드 있음 |
|---|---|---|
| 바닐라 상자/통, Sophisticated 저장소·배낭 | 열었을 때 기억 | 실시간 |
| Create 금고 | 불가 (금고 내용물은 클라이언트에 전송되지 않음) | 실시간 |

## 빌드

JDK 21 설치 후 `gradle wrapper --gradle-version 8.10.2`, `./gradlew build`.
GitHub에 올리면 `.github/workflows/build.yml`이 자동으로 빌드해 Actions의 Artifacts에 jar를 올립니다.

## 설정 (`config/insight_addons-client.toml`)

- `containers.blocks` — 대상 블록 ID 목록 (`*` 와일드카드)
- `memory.enabled` — 열었던 보관함 기억
- `nearDisplay.*` — 아이콘 수, 크기, 테두리, 업그레이드 표시
- `insightChestsIntegration.*` — 연동 대상 블록 패턴(`blocks`), `keepOriginalScreen`, `glassSkin`, `glassOpacity`
- `wrenchScan.*` — 반경, 항목 수, 라벨 on/off 등
- `recipeFocus.*` — JEI 재료 표시 유지 시간, 아이콘 크기, 재료당 표시할 보관함 수

## 같이 들어 있는 외부 파일

`libs/jei-api-19.44.0.401.jar` — JEI 19.44.0.401에서 `mezz/jei/api` 클래스만 뽑은 컴파일용 파일입니다. (JEI는 MIT 라이선스, 제작자 mezz) 실행할 때는 설치된 JEI를 씁니다.

## 알려진 한계 (아직 인게임 테스트 못 함)

- 유리 스킨은 Sophisticated Core 1.4.87 기준 내부 메서드에 붙습니다. 모드 업데이트로 바뀌면 조용히 꺼지고 원래 화면이 나옵니다. 위치와 크기는 원래 값을 그대로 쓰므로 배치는 달라지지 않지만, 색 대비는 인게임에서 확인이 필요합니다.
- 통, 셜커 상자, 배낭은 InSight Chests의 상자 내부 공간(높이 약 0.5)을 블록 모양에 맞게 바꿔 아이템 물리와 속 빈 내부를 맞춥니다(1.5.1). 수치는 추정이라 인게임에서 어색하면 알려 주세요. 카메라 각도는 아직 상자 기준입니다.
- JEI 버튼 아이콘은 직접 그린 9x9 그림이라 JEI 버전에 따라 위치가 조금 어색할 수 있습니다.
- 컴파일과 실행 검증이 끝나지 않았습니다. 오류가 나면 로그를 알려주세요.
- 기억 방식은 열었던 시점의 내용입니다. 다른 사람이나 자동화가 바꾼 것은 다시 열어야 반영됩니다. 게임을 끄면 기억은 사라집니다.
- 놓인(블록) 배낭만 대상입니다. 들고 있거나 착용한 배낭은 위치가 없어서 표시할 수 없습니다.
- InSight Chests 연동은 내부 메서드에 의존합니다. 모드 업데이트로 바뀌면 조용히 꺼집니다.
- Sophisticated Storage의 상자/통은 모양이 바닐라 상자와 달라서 InSight Chests의 3D 공간이 어색할 수 있습니다.
- 서버는 요청 좌표의 내용물을 그대로 알려주므로 잠금 상자의 내용물이 노출될 수 있습니다. (서버에 모드를 설치한 경우)

## 1.16.0 변경 사항

단축키는 조작 설정의 "Insight Addons" 항목에서 바꿀 수 있습니다.

- **보관함 검색 (G)** — 아이템 이름을 입력하고 Enter(또는 클릭)하면, 그 아이템이 든 주변 보관함이 3D/테두리/연결선으로 표시됩니다. JEI/EMI "이 아이템 찾기"와 같은 표시라서 휠 선택, 클릭 꺼내기, 다 꺼내면 자동 꺼짐이 그대로 됩니다.
- **보관함 이름표 (N)** — 보관함을 바라보고 N을 눌러 이름을 붙입니다(비우고 Enter: 삭제). 3D 표시 제목과 재료 찾기의 보관함 라벨에 "★ 이름"으로 나옵니다. 내 컴퓨터(config/insight_addons_names.json)에만 저장되며 다른 플레이어에게는 보이지 않습니다.
- **필요 재료 목록 (L, ;)** — JEI/EMI 재료 찾기를 켠 상태에서 L을 누르면 그 레시피의 재료가 목록에 합산됩니다. 화면 왼쪽에 `인벤토리 개수/필요 개수`가 색(빨강→초록)으로 표시되고 다 모으면 ✓가 붙습니다. `;` 키로 표시/숨김, Shift+`;`로 비웁니다. config/insight_addons_list.json에 저장됩니다.

## 1.15.0 변경 사항

- **AE2 단말기 3D 진열대** — 조합 단말기, 패턴 인코딩 단말기 등 ME 단말기를 열면 네트워크(셀)에 든 아이템 상위 40종이 창 왼쪽 옆 공중에 3D로 떠서 개수와 함께 보입니다. 단말기에서 아이템을 꺼내면 그 아이템이 진열대에서 플레이어에게로 날아가고, 넣으면 플레이어에게서 날아옵니다(소리 포함). 단말기가 이미 클라이언트로 받아 둔 목록을 읽으므로 서버에 이 모드가 없어도 동작합니다.

## 1.14.0 변경 사항

- **다른 작업대에도 머리 위 연출** — 작업대·인벤토리 조합뿐 아니라 대장장이 작업대, 모루, 숫돌, 지도 제작대, 석재 절단기, 베틀, 화로류(화로/용광로/훈연기), 양조기에서도 재료 칸과 결과가 머리 위에 뜹니다. (양조기는 결과 칸이 없어 재료만 보입니다. 모루는 경험치가 모자라면 완성 연출이 나오지 않습니다.)
- **AE2 단말기를 열고 "찾기"를 누를 때** — 서버 조회와 별개로, 열려 있는 단말기(조합/패턴 인코딩 등)가 받아 둔 네트워크 목록을 직접 읽어 재료 위치로 취급합니다. 서버 조회가 실패해도 단말기를 열어 둔 동안은 ME 저장소의 아이템이 잡힙니다. AE2 조회 성공/실패는 `latest.log`에 "AE2" 로 시작하는 줄로 남깁니다.

## 1.13.0 변경 사항

- **JEI/EMI 재료 표시를 시야 정면으로** — 카메라가 바라보는 방향 정면(십자선 위쪽)에 놓여서 고개를 돌리지 않아도 보입니다. 제목은 "제작: 결과 아이템", 개수는 `인벤토리 개수/필요 개수`로 표시하고 빨강→주황→노랑→초록(목표에 가까울수록 초록)으로 색이 바뀝니다. 마우스 휠로 재료를 넘길 때 소리가 납니다.
- **개수 글씨 정리** — 작은 아이콘의 개수는 자기 칸 폭에 들어갈 때만 그리고, 서로 겹치면 중요한 것만 남깁니다. 보관함 이름·합계·기록 시각은 한 줄로 합쳤고, 바라보는 아이템의 이름·정확한 개수·조작법은 십자선 아래에 크게 나옵니다. 렌치 표시도 같은 방식으로 정리했습니다.
- **머리 위 작업대 연출** — 작업대(조합 칸+결과 칸 화면)를 열면 머리 앞쪽 위에 조합 칸이 떠서, 재료를 올리고 빼는 대로 아이템이 날아와 놓이고 사라집니다(소리 포함). 결과 옆에는 만들어질 아이템이 미리 보이고, 조합하면 완성품이 크게 떠올라 파티클·소리와 함께 자연스럽게 사라집니다. 내 화면에서만 보입니다.

## 1.12.1 변경 사항

- **YACL 설정 화면** — YetAnotherConfigLib(YACL 3)가 설치되어 있으면 모드 목록의 "설정" 버튼이 YACL 화면을 엽니다(섹션별 그룹, 한국어/영어). YACL이 없거나 화면을 만들지 못하면 NeoForge 기본 설정 화면으로 대신합니다. 설정 항목은 자동으로 읽어 오므로 새 설정이 생겨도 화면에 바로 나타납니다. 목록 설정은 쉼표로 구분한 한 줄로 편집합니다.

## 1.12.0 변경 사항

- **모드별 렌치 스캔** — 도구마다 보여줄 모드 아이템이 다릅니다: Create 렌치 → Create, Mekanism 구성기(Configurator) → Mekanism, AE2 인증/네더 석영 렌치 → AE2. 설정(렌치 스캔 → 렌치 도구 목록)에 `도구아이템ID=모드ID` 한 줄을 추가하면 다른 모드 도구도 지원합니다. 모드 ID를 비우면 모든 아이템을 보여줍니다. 설정 화면은 한국어/영어를 지원합니다.

## 1.11.0 변경 사항

- **개수/이름 글씨를 화면 위 글씨(HUD)로 변경** — 3D 글꼴이 셰이더·렌더 순서 때문에 안 보일 수 있어서, 3D 위치를 화면에 투영해 GUI 글씨로 그립니다. 거리에 맞춰 크기가 변하고 항상 아이템 위에 보입니다.
- **B키로 연 배낭은 건드리지 않음** — 유리 스킨, 위치 이동, 배경 처리, 글씨 색 변경은 "설치된 Sophisticated 배낭/보관함 블록"을 바라보며 열었을 때만 적용됩니다.
- **배낭 화면에서 EMI 검색창 제거(표시 비율 슬라이더는 유지)** — 설치된 배낭/보관함 화면이 열려 있는 동안만 EMI를 끄고, 닫으면 되돌립니다.
- **AE2 단말기 연동** — 단말기가 붙은 케이블을 바라보면 네트워크 내용이 3D+개수로 표시되고, 조합/패턴 인코딩 단말기를 열어도 화면이 어두워지지 않아 3D가 그대로 보입니다. JEI/EMI 재료 찾기와 클릭 꺼내기도 ME 네트워크를 봅니다(같은 네트워크는 한 번만 집계).
- **Mekanism 연동** — 개인 상자(personal_chest)와 저장통(*_bin)을 3D로 표시하고 꺼낼 수 있습니다. 설정에서 끌 수 있습니다.

## 1.10.0 변경 사항

- **배낭 설정 화면이 까맣게 나오던 문제 수정(추정)** — Sophisticated의 설정 화면(SettingsScreen)은 저장소 화면과 다른 클래스라 어두운 막과 불투명 배경이 남아 있었습니다. 이제 그 막을 없애고 InSight 유리 패널/투명도로 그립니다. 유리 컨트롤 투명도도 조금 낮췄습니다.

## 1.9.0 변경 사항

- **배낭/Sophisticated 슬롯 어긋남 수정** — 유리 패널·슬롯 칸·업그레이드 칸이 실제 슬롯 위치(guiLeft/guiTop) 기준으로 그려집니다.

- **클릭으로 꺼내기** — 3D 아이템을 바라보고 클릭하면 한 스택, Shift+클릭이면 전부 인벤토리로 옵니다(서버에도 이 모드가 있어야 함).

- **모드 설정 화면(한국어)** — 모드 목록의 "설정" 버튼으로 열립니다. NeoForge 기본 설정 화면을 쓰므로 YACL이 없어도 동작합니다.
